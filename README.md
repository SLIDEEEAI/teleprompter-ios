# Телесуфлер для iPhone

Отдельный проект, не связанный с Сивкой. SwiftUI + AVKit. Текст, скорость и размер шрифта сохраняются локально, без сервера и рекламы.

## Версия 0.2: прямые кадры
Вместо создания MP4 и воспроизведения AVPlayer текст рисуется в пиксельные буферы и передаётся непосредственно в AVSampleBufferDisplayLayer / Picture in Picture.
Состоянием прокрутки управляет приложение через AVPictureInPictureSampleBufferPlaybackDelegate.
Приложение сообщает системе, что фоновое воспроизведение аудио запрещено. Микрофон не используется. Аудиосессия не активируется повторно в ответ на прерывания.
Это эксперимент: устойчивость PiP во время записи в других приложениях пока НЕ подтверждена.

Первый прототип с AVPlayer был установлен пользователем через AltStore на iPhone 17 Pro / iOS 27.0. По его тесту во всех проверенных приложениях начало записи скрывало PiP за край экрана и ставило текст на паузу. Поэтому видеоплеер заменён прямыми кадрами.

## Проверка новой версии
1. Вставить короткий текст, выбрать скорость и размер букв.
2. Нажать «Применить текст и настройки».
3. Открыть плавающее окно: первые три секунды прокрутки текст неподвижен.
4. Перейти в Камеру и начать запись.
5. Если PiP скрывается, попробовать вернуть его за боковой язычок и нажать продолжение, не прекращая запись.
6. Проверить движение текста и голос в сохранённом ролике.
7. Повторить для Instagram, видеокружка Telegram и сторис Telegram.
8. После возвращения записать строку состояния из приложения.
9. Проверить «Готово» над клавиатурой, закрытие клавиатуры прокруткой и тапом на предпросмотр/подписи.

После изменения текста или настроек нажмите «Применить» снова. Максимум 20 000 символов. Прокрутка останавливается в конце. Во время редактирования активного PiP нажмите паузу.

## Бесплатная сборка и установка
Actions → успешная сборка → артефакт Teleprompter-unsigned → распаковать ZIP → Teleprompter-unsigned.ipa.
Стандартный macOS runner в публичном репозитории; не включайте платные larger runners.
Файл не подписан, установка выполняется локально через AltStore Classic / AltServer на Windows.
На iPhone: AltStore → My Apps → плюс → выбрать IPA. Для обновления используется тот же bundle ID; прежнее приложение удалять не нужно.
Инструкция: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
Бесплатная подпись требует обновления каждые семь дней. Apple Account и пароль не добавлять в GitHub.

## Разработка
XcodeGen создаёт Xcode-проект из project.yml. Минимальная версия iOS 17, целевое тестовое устройство пользователя — iOS 27.0.
Сборка проверяет компиляцию, но не заменяет проверку PiP на устройстве.
