# Телесуфлер для iPhone

Самостоятельный проект, не связанный с Сивкой. Прототип: вставка и редактирование текста, автоматическое локальное сохранение, скорость, размер букв, видеопредпросмотр и системное Picture in Picture.

## Как это работает
Приложение заранее создаёт локальное беззвучное видео с прокручиваемым текстом, затем воспроизводит его через AVPlayer и PiP. Подготовка может занять время. Первые три секунды видео текст неподвижен. После изменения текста, скорости или размера букв нужно снова нажать «Подготовить текст». Ограничения прототипа: 20 000 символов и 20 минут видео. Рекламы и сервера нет.

## Сборка без собственного Mac
Откройте вкладку Actions, выберите успешный запуск Build iPhone prototype, скачайте артефакт Teleprompter-unsigned и распакуйте ZIP. Внутри находится Teleprompter-unsigned.ipa.
GitHub использует стандартный macOS runner. Не включайте платные larger runners.
IPA не подписан: его нельзя просто открыть на iPhone. Подпись и установка выполняются локально через AltStore Classic / AltServer на Windows. Apple Account и пароль не нужно добавлять в GitHub.
Официальная инструкция: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
Бесплатная подпись действует семь дней и требует обновления. Совместимость установщика с iOS 27.0 должна быть проверена отдельно.

## Проверка на iPhone 17 Pro / iOS 27.0
1. Вставить короткий текст, настроить параметры и подготовить видео.
2. Запустить предпросмотр, открыть PiP, поставить его на паузу.
3. Перейти в целевое приложение, возобновить текст через PiP и записать видео.
4. Повторить отдельно для Камеры, Instagram, видеокружка Telegram и сторис Telegram.
5. Проверить, что текст движется, запись продолжается, голос есть в сохранённом видео.
6. Проверить паузу, продолжение, возврат в приложение и повторную подготовку.
7. Проверить поворот экрана и влияние смены приложения.

Совместимость с записью в сторонних приложениях НЕ подтверждена. Приложение использует смешиваемую playback-аудиосессию, однако другое приложение может прервать её. Это критический критерий тестирования.
Если PiP недоступен, проверьте Настройки → Основные → Картинка в картинке. Для установки собственной сборки может потребоваться режим разработчика.

## Разработка
SwiftUI + AVKit. XcodeGen генерирует Xcode-проект из project.yml. Минимальная версия iOS 17; целевое тестовое устройство пользователя — iOS 27.0. Проект не использует API только iOS 27.
Сборка CI подтверждает компиляцию, но не заменяет проверку PiP на физическом устройстве.
